# Security Policy

## Reporting a vulnerability

Do not open a public issue for a security vulnerability. Email [abdrahmanwalied11@gmail.com](mailto:abdrahmanwalied11@gmail.com) instead.

Please include:

- A description of the issue.
- The affected version or commit.
- The adapter in use (`mongoose` or `prisma`).
- Steps to reproduce it.
- The impact you believe it has.

## Response

The maintainer aims to reply within 2 to 3 days. There is no promised fix timeline.

Reports are handled privately until a fix is available.

## Supported versions

freeauth is not published to npm yet. Only the latest commit on `main` is supported.
